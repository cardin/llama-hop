# Artwork

`ponyta.png`: official Ponyta artwork, retrieved from
https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/77.png

Pokémon and character artwork belong to their respective rights holders.

`ponyta.svg` is a color spline trace of `ponyta.png`, generated using VTracer
0.6.15 (stacked color paths, speckle filter 4, color precision 6, layer difference
16, corner threshold 60, length threshold 3.5, splice threshold 45, path precision
2). Both files are retained as tracing references; the Ponyta form is now drawn
directly in canvas and does not load either file.

`goku-emblem.ttf`: Google Fonts Noto Sans SC Bold, subset to the 悟 character
for consistent canvas rendering without system CJK fonts. Licensed under the
SIL Open Font License; see `goku-emblem-OFL.txt`.

`ora-sfx.ttf`: Google Fonts Noto Sans JP Black (900), subset to オラッ！
for the Jotaro hop sound effect. Licensed under the SIL Open Font License;
see `ora-sfx-OFL.txt`.

`menacing-sfx.ttf`: Google Fonts Noto Sans JP Medium (500), subset to ゴ
for the faint ゴゴゴ trail. Licensed under the same SIL Open Font License;
see `ora-sfx-OFL.txt`.
